# ThreadAsync

Web API using FastAPI in Python.

## Install

```
uv sync
```

## Run

```
uv run fastapi dev
```

## Lint

```
uv run ruff check --fix .   # lint + corrections automatiques
uv run ruff format .        # formatage (remplace black)
```

## Prek

Install Prek:
```
uv run prek install
# Then run:
prek run --all-files
```



## Troubleshooting install

```
uv sync --reinstall
```
